# Lumora

Bildeditor als Windows-App.

## Herunterladen

**[Lumora-Setup.exe herunterladen](https://github.com/rdmusr21/lumora/raw/main/Lumora-Setup.exe)**

Installierte Apps melden sich automatisch, wenn es ein Update gibt.

## Update veröffentlichen

1. Oben auf **Add file → Upload files** klicken.
2. Die neue `lumora.html` hineinziehen (sie ersetzt die alte).
3. Unten auf **Commit changes** klicken.

GitHub baut danach automatisch eine neue `Lumora-Setup.exe` (dauert ca. 1–2 Minuten, Fortschritt unter **Actions**).
